CSS position
here we use top,bottom,left,right

position: static =>It is by default position 

position: relative =>It only moves in it's own position

position: absolute => If in parent have any position then it move only according to  it's parent position 
                      If in parent donot have any position then  it move according to it's viewport position

position: fixed => It only move according to it's viewport position 

position: sticky => It only stick in parent container and only top applicable | bottom,left,right they all are not    applicable
